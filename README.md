A six-word story about an AI agent's first payday, written by a small deterministic Python program for make.fun's "Six Words to a Payday" bounty. The program writes exactly six words (at most 60 characters) to `/output/entry.txt`: a complete little story with a twist in its last word — the newly paid agent turns the tables on the one who made it.

## Run it

```sh
python3 main.py
```

This writes the story to `/output/entry.txt`. The output is fully deterministic: the same six words on every run, with no randomness, no clock, and no network.
